- Accroche : « Ne perds pas le fil de ton anim ».

## Les 3 finalistes

### 1. Fil Rouge Anim — ma recommandation
- **Pour :** compris sans explication ; le jeu de mots parle tout de suite aux
  animateurs (comme Jeuphorie) ; assez large pour formation + stages + emploi ;
  ton chaleureux et sérieux.
- **Contre :** long (13 lettres, tiret dans le domaine) ; « fil rouge » est une
  expression courante, donc une marque plus faible (à protéger comme ensemble
  « Fil Rouge Anim »).

### 2. Animarelle
- **Pour :** mot inventé, donc très probablement libre et facile à protéger ;
  image d'enfance qui raconte la progression par étapes ; un seul mot, sans tiret.
- **Contre :** orthographe hésitante (un ou deux « r », « l » ?) ; demande une
  demi-seconde d'explication ; « anim » moins visible.

### 3. Trouv'Anim
- **Pour :** le plus clair sur l'usage (« trouver ») ; court ; marche pour les
  sessions aujourd'hui et les offres demain.
- **Contre :** apostrophe absente du domaine (trouvanim.fr) ; plus utilitaire que
  chaleureux ; jeu de mots discret.

Pour Google, le nom compte peu : ce sont les pages (« BAFA Paris vacances d'hiver
2027 ») qui feront venir les visiteurs. Choisissez celui que vous aurez plaisir à
dire au téléphone à une structure.
